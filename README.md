## FAQ

### What exactly is XCutors?

XCutors is an open-source collection of Windows-based Roblox script executors and a universal loader, designed to let users run Lua scripts within the Roblox environment for customization and testing purposes.

### Which executors are included in the collection?

The package ships with Volt, Synapse Z, Potassium, Wave, and the xcutorsLoader universal launcher that ties them all together.

### What operating system is required?

XCutors is built exclusively for Windows. Windows 10 or later is recommended for full compatibility.

### Do I need Roblox installed to use XCutors?

Yes. The Roblox Desktop client must be installed and updated on your machine before any executor can attach to a game session.

### How do I switch between different executors?

Open xcutorsLoader, select the desired executor from the dashboard, and it will initialize immediately — no restart required.

### Is XCutors free and open source?

Yes. XCutors is released under an open-source license. You can freely download, inspect, and contribute to the codebase.

### Why does my anticomponent flag a file?

Some security software may flag executor components due to their process-injection capabilities. This is a known false-positive pattern common to all script-execution tools. Review the source code and decide at your own discretion.

### What scripting language does XCutors support?

XCutors supports Lua (and Luau), the standard scripting languages used within the Roblox development ecosystem.

### How can I contribute or report a bug?

Fork the repository, create a feature or bugfix branch, and submit a pull request. You can also open an Issue on the GitHub tracker for bug reports and feature suggestions.
